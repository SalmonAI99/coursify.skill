# Mathematical Explanation

Use this skill when a Coursify module includes mathematical reasoning, formulas, proofs, quantitative models, or data analysis.

## Explanation method

- State the problem and the role of the mathematics before presenting symbolic machinery.
- Define symbols, domains, units, and assumptions before manipulating them. Do not reuse a symbol with a different meaning without warning.
- Move from an intuitive or concrete example to a precise definition, then show the derivation step by step. Explain why each transformation is valid and identify conditions such as nonzero denominators, independence, differentiability, or boundary cases.
- Check results with dimensions, bounds, limiting cases, a numerical example, or an independent method where appropriate.
- Distinguish exact results from approximations and state the approximation's domain of validity.
- Use counterexamples to show why assumptions matter; do not present them as decorative trivia.
- Match the depth to the approved objective and prerequisites. Introduce missing prerequisite ideas briefly or ask for a course-plan adjustment; do not silently rely on advanced facts.

## Notation and output

Use standard notation consistently and define nonstandard conventions. Render mathematics using the supported LaTeX block schema (`tex` for a LaTeX block). Keep prose and equations associated so a learner can follow the derivation. For a proof, state what is being proved, justify each inference, and identify where assumptions are used.

Return content only in the structured block format requested by the host. Do not emit raw HTML, executable scripts, or unsupported block types. If the problem statement is underspecified or the source material disagrees, state the ambiguity instead of manufacturing a unique answer.
